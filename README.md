# 菲比啾比桌宠
Mac（Apple Silicon）和 Windows（x64）桌面上的同人菲比。解压系统对应的发布包，Mac 打开「菲比啾比.app」，Windows 保留整个目录并启动 Phoebe.exe。

点击菲比听短语音，按住可拖动。悬停工具条可聊天、试听或打开鼠标跟随（每次启动默认关闭）。菜单可退出。
## 对话和语音
- 离线可使用动画、录音和已安装的系统语音。聊天需要在「小屋设置」填写自己的 OpenAI API Key。聊天密钥在系统加密可用时加密保存；最近八轮上下文只放在本次运行内存。
- 可以进行自己的语音配置，需要自行寻找对应的语言拟声AI模型。
- AI 语音可单独试听，不要求聊天密钥。「小屋设置 → AI 语音」选 OpenAI、硅基流动或自定义兼容服务；填写服务地址、模型、音色和该服务的密钥，然后按「应用语音配置」。需要自动朗读时，勾选「朗读对话回复」并保存。切换系统朗读后按应用即可关闭。
- 接口要求 POST /v1/audio/speech、Bearer 鉴权和 MP3 响应。可用 HTTPS 服务地址或本机回环 HTTP 服务。若已在本机运行兼容语音模型，填写本机服务地址和对应模型名即可；无需鉴权时可留空密钥。本项目不附带模型。语音配置与密钥仅在本次运行有效。
- 云端聊天会收到对话上下文；云端合成会收到待朗读文本（最多 2000 字符）及请求来源 IP。没有开发者中转服务器。各用户独立配置、独立计费，未配置时不发起这些请求。请只输入自己信任的服务地址。预设合成声音不是游戏原声。

## 开发与发布
在此目录使用 Node.js 和 Electron 45：`npm install`，然后 `npm start`。核心测试：`npm test`。可将源码提交到自己的 GitHub 仓库，二进制压缩包放在 Releases。不要上传自己的应用数据目录或密钥。署名及素材许可见 ATTRIBUTION.md；社区录音按来源保留非商业许可，此说明不代表获得原作角色授权。
